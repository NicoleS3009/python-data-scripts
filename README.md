# python-data-scripts
Colección de scripts, herramientas de automatización y modelos algorítmicos desarrollados en Python para el procesamiento de datos, análisis técnico y resolución de problemas.

## 📁 Proyectos Incluidos

### 1. 📸 PDF Media Extractor (`/pdf-extractor`)
Herramienta CLI para la extracción y filtrado inteligente de imágenes/capturas desde informes en PDF utilizando `poppler-utils`. Elimina logos y elementos decorativos mediante umbrales de dimensión configurables.

### 2. 🌳 Grundy Game State Tree Solver (`/grundy-solver`)
Modelado algorítmico jerárquico para Teoría de Juegos. Genera y renderiza visualmente el árbol de espacio de estados utilizando `NetworkX` para la representación de grafos dirigidos y `Matplotlib` para la visualización.

## 🧰 Stack Tecnológico
- **Lenguaje:** Python 3.x
- **Análisis y Visualización:** `NetworkX`, `Matplotlib`, `Pandas`
- **Utilidades:** `poppler-utils`, `subprocess`, `argparse`
- **Entornos:** Google Colab, VS Code / Codespaces (`.venv`)
